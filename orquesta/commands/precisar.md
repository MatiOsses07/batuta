Reescribe este pedido como un prompt preciso, sin ejecutarlo: $ARGUMENTS

Estructura:
- **Objetivo**: una frase con el resultado esperado.
- **Contexto**: datos, rutas, periodo, campo/especie u otros que se desprendan del pedido o del chat. No inventes ninguno.
- **Restricciones**: lo que no se debe tocar o hacer, y las reglas del usuario aplicables.
- **Formato de salida**: cómo debe entregarse (tabla, correo, archivo, extensión).
- **Dudas abiertas**: máximo 3 datos que faltan y cambiarían el resultado; si no hay, omitir la sección.

Entrega el prompt en un bloque de código para copiarlo y pregunta si lo envías tal cual o lo ajustas. No ejecutes la tarea. Respuesta breve, en español.
